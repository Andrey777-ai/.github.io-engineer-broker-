🌍 Проблема: «Цифровая Вавилонская башня»

Современная промышленность — это зоопарк из АСУ ТП, MES, ERP и CAD-систем. Они работают на разных протоколах (OPC UA, Modbus, Profibus) и не понимают друг друга. Интеграция нового станка занимает от 6 месяцев до года, а данные переписываются вручную, что ведет к ошибкам.

📲 Умные Web-алерты вместо устаревших СМС

Традиционные системы шлют СМС через GSM-модемы (дорого, ненадежно, без деталей). Наш брокер транслирует события напрямую в интернет по защищенным каналам (WebSockets / MQTT).

Мгновенные Push-уведомления

  • Интеграция с Telegram / Max / Mattermost.
  • Вместо сухого «Ошибка 404» инженер получает полный JSON-контекст аварии.
  • Возможность подтвердить получение или запустить скрипт реакции прямо из мессенджера.
  • Гибкая маршрутизация: аварии — главному инженеру, а плановые отчеты — в бухгалтерию.

🛡️ Безопасность, Криптография и Соответствие КИИ

Работа на объектах Критической Информационной Инфраструктуры (КИИ) требует особого подхода. Платформа спроектирована с учетом требований ФСТЭК.

🔐 Отечественная криптография

Поддержка алгоритмов ГОСТ 34.12-2018 («Кузнечик», «Магма») и ГОСТ 34.10-2012 для электронной подписи. Все каналы шифруются по TLS 1.3 с возможностью замены на ГОСТ-шифрование (через сертифицированные криптопровайдеры, например, КриптоПро).

🛡️ Zero Trust и mTLS

Взаимная аутентификация (mTLS) между адаптерами и ядром. Каждый пакет данных проверяется. Даже если злоумышленник получит доступ к сети завода, без валидного сертификата устройства он не сможет отправить или перехватить данные.

📜 Неизменяемый аудит (WORM)

Все действия (вход, смена конфигурации, трансформация данных) пишутся в базу с защитой от перезаписи (Write Once Read Many). Это позволяет провести форензику в случае инцидента и доказать чистоту данных.

🐳 Изоляция в Docker

Работает на защищенных ОС (Astra Linux SE, РЕД ОС). Все компоненты изолированы в контейнерах. Права доступа к файловой системе минимальны (Read-Only там, где это возможно).

⚙️ Архитектура и Технологический стек

Наш брокер разворачивается On-Premise (внутри контура завода), обеспечивая высочайший уровень безопасности.

🐳 Среда (Docker)

Все компоненты изолированы в Docker-контейнерах. Работает на Astra Linux (Special Edition) или РЕД ОС (для КИИ). Управление через Kubernetes.

🗄️ Базы Данных

Kafka (Redpanda) — для шины сообщений (5000 событий/сек).
TimescaleDB — для временных рядов датчиков.
PostgreSQL / Postgres Pro — для конфигураций и аудита.
Redis — кэш для ИИ-движка.

🛡️ Безопасность (ФСТЭК)

Связь по mTLS (TLS 1.3). Ролевая модель доступа (RBAC). Неизменяемый аудит (WORM). Подпись всех адаптеров. Платформа проектируется с учетом требований к объектам КИИ.

🧠 ИИ-Движок

Написан на Python. Не использует LLM (чтобы избежать галлюцинаций). Работает на базе онтологий (Rule-based) + эмбеддинги для Semantic Matching (сопоставления тегов датчиков).

💻 Живая демонстрация: От хаоса к порядку

Симулятор реального времени. Обратите внимание: когда система фиксирует аномалию, в правом нижнем углу экрана срабатывает Web-алерт (имитация push-уведомления).
